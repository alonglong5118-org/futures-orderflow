# P0 价差影子盘预注册（2026-10-08 v1）

> 与 edge 预注册（`orderflow-edge-preregistration-20261004.md`）并列的**第二份预注册**。
> 铁律一致：判据跑前定死、只增不改、不偷看盈利。本文件在观测窗开始前定稿，判定日只做「套用」，不做「调整」。

## §1 目标（Goal）
校验「跨期价差（近月−远月）z-score 极端偏离监控」这条信号链路的
**数据管线完整性 + 信号行为合理性**，作为该信号能否进入四维系统的前置 sanity gate。

⚠️ **本 P0 不验证盈利能力**（那是 edge 研究的事）。它只回答一个问题：
**这个信号源本身有没有退化、失效、或产出垃圾**。是 / 否。

## §3 观察窗（Observation Window）

## §4 预注册判据（跑前定死 · 只增不改）
四道 gate，全部 PASS = P0 通过；任一 FAIL = P0 不通过；灰区 = 延到 60/90 日再判。

- **P0-G1 数据完整性**
  观测窗内「成功产出 CSV 行数 / 应有交易日」≥ 19/30。
  FAIL → launchd/akshare 管线故障，先修基础设施。

- **P0-G2 退出预热**
  判定日时，`n_samples ≥ 61`（z 可算）的品种数 ≥ 12/18。
  低于此 → **触发「换长历史源」决策（§6.1）**，本窗判 FAIL 但**非信号失效**（是数据长度问题）。

- **P0-G3 信号非退化**
  全窗累计（品种×日）中触发信号（|z|≥1.5）占比 ∈ [0.5%, 15%]：
  - = 0% → 信号逻辑疑似失效（阈值/数据异常），判 FAIL；
  - > 15% → 阈值过松或数据失真（过度触发），判 FAIL。

- **P0-G4 z 分布合理**
  全窗 z 的 |z| 极大值 ≤ 3.5（无数值爆炸 / 除零伪装），
  且 z 均值 ∈ [−0.5, 0.5]（无系统偏移）。任一越界 → 判 FAIL。

## §5 统计方法
- 占比 = 触发信号行数 / 全窗有效行数（**剔除「预热中」行**）。
- z 极值 / 均值基于所有 z 可算的行（signal ∈ {空价差, 多价差, —}）。
- 不做 bootstrap（样本是日频 18 品种，非高频）；判定用**固定阈值带**。
- 多重比较：本 P0 为**单一 family**（价差监控），不作 Bonferroni 惩罚
  （与 edge 的 11-family 不同，不因本项引入族系校正）。

## §6 灰区 / 失败处置（预注册）
- **§6.1 换长历史源**（对应 P0-G2 FAIL）：
  不改判据，用回测 `fixed.csv` 同口径月差序列**回填长历史**，使 n_samples 立即 ≥ 61，
  重新观测。回填口径须与 akshare 近−远月价差定义逐位一致（价差 = 近月收 − 远月收）。
- **§6.2 信号逻辑 FAIL**（P0-G3/G4 FAIL）：
  先查 akshare 数据质量（合约代码还原 `_nearest_symbol`、除权、停板），
  再决定修脚本 or 判死。修脚本属「改测量定义」，**须重新预注册**新判据。
- **灰区**（G1 临界 19/30 但 G2–G4 模糊）：延到 60/90 日再判，**不中途调整参数**。
