四、结论与下一步

1. 不要全市场切 combined：朴素 always-combined 的 OOS 期望R 均值 +0.744，弱于基线 +0.787（与前期全样本 Δ=−0.0129 一致）。
2. 选择性启用也救不了 combined：即便加了「IS 决策 + 三道护栏」，选择性策略 OOS 期望R 均值 +0.756，反而低于基线 +0.787（Δ选−基 -0.031）。 41 个品种仅 2 个被放行(rb/PF)，而这 2 个在 OOS 全部不及阈值基线（真赢 0 / 假阳 2）——即 IS 增益未转移到 OOS。
3. 根因 = combined 的边缘是非平稳的：以 rb 为例，IS 期 combined 比 threshold 高 +0.836R，OOS 期却低 −0.599R；前期全样本"rb +0.46"只是早段优势的时间平均假象。 说明 F/C 当方向决策者带来的增益集中在少数时段，无法被 IS 窗口稳定预测。
4. 生产建议：维持 threshold（现状）。无论是全市场切、还是 IS 选择性启用，combined 都不能在 OOS 上稳定胜出；盲目上线只会拖累（本实验 Δ选−基 -0.031 即证据）。
5. 真正的资金面 C 应走盘中实时 C_flow（tick 订单流），而非日线龙虎榜回填——日线 C 区间太短无法严格验证，且本实验已 ablate="C" 隔离该短板，纯测 F 定方向仍无稳定增益。
6. 若仍想挖掘：需做「regime-conditional combined」（仅在检测到的特定 regime 下启用）并重新走 IS/OOS 验证，或接实时 tick C_flow 后重测。当前证据不足以支撑任何 combined 上线。
